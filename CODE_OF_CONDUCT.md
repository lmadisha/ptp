# Code of Conduct

PTP follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be respectful and constructive.
- Critique code and ideas, not people.
- No harassment, discrimination or personal attacks.
- Never post anyone's location data, device identifiers or other personal information in issues, pull requests or test files.

Report problems to [CONDUCT CONTACT EMAIL]. Reports are handled privately.
